# nest-rs-codegen

Macro crate for the NestRS framework — the shared syn/quote helpers every `nest-rs-*-macros` crate is built from. Third-party macro crates may use it too; application code does not.

Part of [NestRS](https://nestrs.dev) — every framework crate ships at the same version in lockstep, under one [semver policy](https://nestrs.dev/semver/).

```sh
cargo add nest-rs-codegen
```
