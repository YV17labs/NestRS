# nest-rs-config-macros

Macro crate for the NestRS framework — the #[config] decorator macro; re-exported by nest-rs-config: depend on that crate, not this one.

Part of [NestRS](https://nestrs.dev) — every framework crate ships at the same version in lockstep, under a semver contract: breaking changes wait for the next major.

```sh
cargo add nest-rs-config
```

[Documentation](https://nestrs.dev/configuration/) · [GitHub](https://github.com/YV17labs/NestRS)
