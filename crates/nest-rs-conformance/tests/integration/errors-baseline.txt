# Error types declared outside `error.rs`. **It only shrinks.**
#
# The two lines below are one decision, recorded with the fact that makes it one:
# a **wire error document** — the body a client parses when an operation fails —
# implements `Error` so a handler can return it, but its subject is the document.
# `ProblemDetails` is RFC 9457's problem-details object, every HTTP error body, and
# `problem.rs` is where a reader looks for RFC 9457; `WsError` is the WebSocket
# envelope's error frame, beside the envelope it belongs to. Filing either under
# `error.rs` would name it for one of its two uses.

ProblemDetails is declared by crates/nest-rs-http/src/problem.rs
WsError is declared by crates/nest-rs-ws/src/envelope.rs
