# Keys an operator reads outside Rust that no `src/` constant reaches.
# **It only shrinks.** A line removed is a spelling fixed; a line added is a
# regression argued in review, never absorbed by a flag.
#
# Every line below is apalis-redis's layout at the root of the keyspace: the
# 6.x layout, in which the producer and the worker handed apalis the queue's
# bare name as its namespace, so apalis wrote `<queue>:active`,
# `<queue>:inflight`, `<queue>:data` and the rest beside whatever else the
# database holds. The demo chart's KEDA triggers poll two of them, and its
# values, notes and README explain the scaling floor with three more.
#
# The code has moved: the producer and the worker hand apalis the namespace
# `nestrs:queue:<queue>` (`nest-rs-redis/src/layout.rs`), so apalis now writes
# `nestrs:queue:<queue>:active`, and the queue pages spell that. The chart is
# the demo's, and these lines leave when its triggers and notes follow — until
# then KEDA polls a list the 7.0 worker no longer fills, which is what these
# lines exist to keep in view.
