# Keys an operator reads outside Rust that no `src/` constant reaches.
# **It only shrinks.** A line removed is a spelling fixed; a line added is a
# regression argued in review, never absorbed by a flag.
#
# Every line below is apalis-redis's layout at the root of the keyspace: the
# 6.x layout, in which the producer and the worker hand apalis the queue's bare
# name as its namespace, so apalis writes `<queue>:active`, `<queue>:inflight`,
# `<queue>:data` and the rest beside whatever else the database holds. The
# demo chart's KEDA triggers poll two of them, its values, notes and README
# explain the scaling floor with three more, and the retries page shows an
# operator where a dead job lands.
#
# They leave with the queue re-namespacing, which hands apalis the namespace
# `nestrs:queue:<queue>` — so apalis writes `nestrs:queue:<queue>:active` — and
# which moves the producer, the worker, the chart's triggers, its notes and the
# page together, then deletes these lines. Until then the triggers are right
# about what the code writes, and these lines are what keep that move from
# leaving KEDA polling a list nobody fills.
