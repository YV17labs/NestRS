# nest-rs-events-macros

Macro crate for the NestRS framework — the #[listeners] decorator macro; re-exported by nest-rs-events: depend on that crate, not this one.

Part of [NestRS](https://nestrs.dev) — every framework crate ships at the same version in lockstep, under a semver contract: breaking changes wait for the next major.

```sh
cargo add nest-rs-events
```

[Documentation](https://nestrs.dev/events/) · [GitHub](https://github.com/YV17labs/NestRS)
