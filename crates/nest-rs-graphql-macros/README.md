# nest-rs-graphql-macros

Macro crate for the NestRS framework — GraphQL decorator macros (#[graphql], #[resolver]); re-exported by nest-rs-graphql: depend on that crate, not this one.

Part of [NestRS](https://nestrs.dev) — every framework crate ships at the same version in lockstep, under a semver contract: breaking changes wait for the next major.

```sh
cargo add nest-rs-graphql
```

[Documentation](https://nestrs.dev/graphql/) · [GitHub](https://github.com/YV17labs/NestRS)
