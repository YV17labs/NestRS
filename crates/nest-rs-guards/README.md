# nest-rs-guards

Transport-spanning guards for NestRS — one trait, three transports (HTTP, GraphQL, WS), declared once with App::builder().use_guards_global(...).

Part of [NestRS](https://nestrs.dev) — every framework crate ships at the same version in lockstep, under a semver contract: breaking changes wait for the next major.

```sh
cargo add nest-rs-guards
```

[Documentation](https://nestrs.dev/fundamentals/guards/) · [GitHub](https://github.com/YV17labs/NestRS)
