# nest-rs-ws-macros

Macro crate for the NestRS framework — WebSocket gateway decorator macros (#[gateway], #[messages], #[subscribe_message]); re-exported by nest-rs-ws: depend on that crate, not this one.

Part of [NestRS](https://nestrs.dev) — every framework crate ships at the same version in lockstep, under a semver contract: breaking changes wait for the next major.

```sh
cargo add nest-rs-ws
```
